# Voice & Text-Driven AI-RPA Agent 🤖🌐

An intelligent, LLM-powered Browser Automation (AI-RPA) Agent built using **Python**, **Selenium WebDriver**, and the **Gemini API**. This agent bridges the gap between Natural Language Processing (NLP) and robotic process automation by executing complex browser workflows based on simple voice or text commands.

## 🚀 Key Features
- **Contextual Search:** Parses and understands user natural language commands to execute direct Google Searches.
- **Automated Video Streaming:** Programmatically navigates YouTube, queries content, plays the requested video, and intelligently **skips advertisements** to optimize viewing time.
- **Smart Messaging:** Automatically interacts with WhatsApp Web to share information, links, or curated text based on user-granted permissions.
- **Multimodal Inputs:** Supports both manual text inputs and microphone voice commands.

## 🛠️ Tech Stack
- **Core Language:** Python 3.x
- **AI / LLM Integration:** Google Gemini API (for semantic text processing)
- **Browser Automation:** Selenium WebDriver
- **Libraries used:** SpeechRecognition, Pyttsx3 (for text-to-speech feedback)
